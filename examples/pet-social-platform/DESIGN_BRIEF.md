# Design brief (pinned)

This direction is user-pinned — when this surface gets built (via `/impeccable shape` or
`/impeccable new-work`), honor it directly rather than running the concept-seed/decision-page
flow. Per impeccable's own rule: "The brief wins. Honor pinned aesthetics, eras, materials,
fonts, and palettes even when they conflict with a saturated-pattern warning."

This is not DESIGN.md — DESIGN.md gets written from the built world once this surface exists.
This file is the input to that build.

---

Build a distinctive, premium editorial research dashboard.

This is NOT a generic SaaS admin dashboard.

Avoid the typical AI-generated aesthetic:

- excessive rounded cards
- purple/blue gradients
- glassmorphism
- excessive shadows
- oversized icons
- generic Inter/Arial typography
- excessive decorative elements
- meaningless charts
- dense dashboard grids

The visual language should feel like:

- premium product strategy research
- editorial publication
- modern design system
- Linear-level polish
- restrained and intentional

Use a warm off-white / neutral background, dark typography, subtle borders and ONE restrained
accent color.

Use typography and spacing to create hierarchy rather than relying on cards.

Charts should be minimal and analytical.

Large strategic statements should have strong visual presence.

Every visual element must communicate either:

1. research evidence
2. product insight
3. competitive comparison
4. strategic recommendation

Do not add decorative UI that does not communicate information.
