# Research workspace

This folder is the audit trail for the case. Anyone (human or agent) who changes a number or a claim in `data/`
records here what was found, where, and what is still unknown.

- `plan.md` — the research questions per chapter and the data fields each answer feeds.
- `sources.md` — every source cited anywhere in the site, one line each.
- `NN-chapter.md` — findings, sources and open gaps for that chapter.

Conventions: dates ISO (2026-09-04); cite the source name as it appears in `provenance.source`; write what the
source actually measures (region, year, sample), not just the number.

Bilingual rule: data strings are `{ en, zh }` objects. When you change a value or a sentence, change both halves
in the same edit. Research notes themselves may be written in either language.
